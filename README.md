# Password Generator Chrome Extension

A lightweight Chrome extension that generates secure passwords with customizable options for length and character types.

## Features

- Generate random passwords
- Set custom password length
- Include or exclude:
  - uppercase letters
  - lowercase letters
  - numbers
  - symbols
- Copy generated password to the clipboard
- Simple popup-based user interface

## Project Files

- `manifest.json` - Chrome extension configuration
- `popup.html` - popup UI
- `popup.js` - password generation and copy logic
- `style.css` - optional styling file (if used in the project)

## How to Install the Extension in Chrome

1. Open Google Chrome.
2. Go to `chrome://extensions/`.
3. Turn on Developer mode in the top-right corner.
4. Click the Load unpacked button.
5. Select the folder containing this project, such as the `password-generator` folder.
6. The extension will appear in your Chrome toolbar.
7. Click the extension icon to open the popup and generate passwords.

## How to Install the Extension in Microsoft Edge

1. Open Microsoft Edge.
2. Go to `edge://extensions/`.
3. Turn on Developer mode.
4. Click Load unpacked.
5. Select the project folder.
6. The extension is now installed and ready to use.

## How to Use

1. Click the extension icon in the browser toolbar.
2. Choose your password length and character options.
3. Click Generate Password.
4. Click Copy to copy the password to your clipboard.

## Notes

This extension is a basic starter project and can be expanded with features such as:

- password strength meter
- save favorite passwords
- dark mode
- UI improvements
